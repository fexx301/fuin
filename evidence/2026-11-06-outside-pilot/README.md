## What broke, and what changed

| What he hit | Change |
|---|---|
| WSL's DNS couldn't resolve Intel's PCS host (`api.trustedservices.intel.com`), so the run preflight accepted no attestation. Its message, `got 0 accepted attestation candidates`, didn't say why (about 16 minutes to find and fix). | `31aa427`: the preflight names each candidate's outcome and error. `00b4c26`: PILOT.md lists every host the tools reach, plus the WSL DNS fix. |
| `near` wasn't found: `~/.cargo/bin` wasn't on `PATH` in a non-login shell. | `00b4c26`: PILOT.md says to add it. |
| `cargo install near-cli-rs` failed without `libudev-dev`. | `f5cbb98`: PILOT.md step 2 lists the Debian/Ubuntu build packages. |
| There was no keychain under WSL, so `near` saved the key to `~/.near-credentials`. Fūin signed with that file. | `f5cbb98`: PILOT.md says so. It had said a keychain must be running. |
| After `close`, `fuin status` suggested `reveal`, the sampled round's step, on his private round. He didn't run it. | `274bb43`: `status --out DIR` finds the certificates, and on a private round it suggests `tee-score`, then `verify`. A failed gist delete now prints a warning. |
| In his first verify, one dropped request to Intel's PCS printed CAN'T CERTIFY for one certificate. | `fdddbfd`: verify retries a dropped Intel request once. `f5cbb98`: PILOT.md says to rerun on `evidence_unavailable`. |
| Found during our check: an uploaded certificate shows PARTLY CHECKED in the browser, which PILOT.md didn't say. | `f5cbb98` |

Not changed:
- There are no native Windows steps; WSL works.
- uv warns that the build backend's version range doesn't include uv 0.13.7. The warning is harmless.
- The GitHub sign-in retries and the taken testnet name came from his setup, not the kit.

## What this pilot doesn't show

- **The questions were synthetic.** No one wrote a real private suite.
- **The independent verifier was Fūin's builder,** on a different machine, OS and network from the owner's, not a third party.
- **Two answers are still pending from him:** his NEAR AI cost, and whether he'd use Fūin for a real benchmark.
- **Privacy:** the certificates name his testnet account. Through the scorer's request URL, they also name the GitHub account that hosted the gists (`JUICEWRLD998`).

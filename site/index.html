Fūin

Fūin · 封印 · pronounced foo-een · Japanese for "seal"

Private benchmark results that anyone can check without an account and without the test set. The test set is sealed on NEAR before any model runs, every answer is signed by the model's TEE key on NEAR AI Cloud, and a future NEAR block picks which answers are revealed and re-scored.

Two bad options

Publish the test set, and it leaks into the next model's training data. Keep it private, and everyone has to take the owner's word for the scores.

What Fūin proves

A named model in an attested TEE produced every committed answer, unedited. The set was sealed before the results were committed. The owner couldn't pick the audited items. The revealed answers re-score to the committed scores.

Check it yourself

Everything on this page is recorded output from committed files. Run the same checks; you need no account and no API key:

git clone https://github.com/fexx301/fuin && cd fuin
./scripts/review.sh        # verifies every certificate, all fixtures and the tests; about 5 minutes

Limits, printed with every verdict: score correctness is checked on the revealed sample only; instances of a model can share a signing key; the deployment trace is taken at preflight, and image build provenance is not verified; discarded or uncommitted runs can't be seen; the sample assumes NEAR block hashes are unpredictable; reveals permanently disclose their questions; the seal precedes the result commitment, which doesn't prove when inference happened. Testnet only.
